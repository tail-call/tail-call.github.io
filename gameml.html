Game Theoretic Framework for Neural Network Architecture Design

  • A pre-preprint
  • by Maria Zaitseva <maria@tail-call.ru>

Abstract

Machine learning, often seen as a complex and technical field, can be better understood as a dynamic game where data scientists and models continuously strive for optimal performance. This perspective highlights the game-like nature of training, scoring, and evaluating models, where each hyperparameter choice and training decision is akin to a strategic move. This paper explores the idea of breaking down these high-level games into lower-level subgames, focusing on decision-making within learning algorithms. By integrating conditional branches and dynamic strategies, we can create games that not only optimize machine learning tasks but also address ethical and cognitive aspects of AI. The paper further draws parallels to biological systems, suggesting that human cognition and emotions can be modeled as games, which may inform AI ethics. Ultimately, viewing machine learning as a series of nested games can enhance our understanding of both the technical and ethical dimensions of AI development.

Introduction

Machine learning is inherently a game. We train models, score them, evaluate, compare, and rank them. For any task, there's a top model and a bottom model. New models constantly vie for the top spot, pushing others down the leaderboard. It's a world record game where endless players compete for the best metrics.

Compositionality exists for stubbing. To study a subgame individually, one would stub it's environment and observe the subgame in isolation. How do we stub an environment? - Simple, just record the real process, abstract it away into a data frame and then you may shape this data as you want and see how different changes issue a different response from your individual unit.

CGT is a unit testing framework for ML.

Training a model and receiving a score is like playing a game from start to finish. You perform tasks—predicting, generating text or images—and get a score. You may do better or worse.

In this model, the only player is the data scientist1, who chooses hyperparameters and initiates training. Hyperparameter choice is a move, and the score is the outcome. Winning is getting a model that solves the problem well.

Data scientists can automate hyperparameter search, entering a higher-order game. This new game includes the original as a subgame, with endless decisions to make.

Creating higher-order games is easy—just contextualize the current game within a larger activity. But I'm more interested in breaking the game into lower-level games. This is challenging because few decisions are made by the network or algorithm. To go lower, we need to incorporate decision-making into the learning algorithm, ensuring different decisions lead to different outcomes.

For this framework to work, a learning algorithm must include conditional branches. Think of a decision tree: it splits data subsets, making decisions to maximize score. In game-theoretic sense, the way it splits data is its strategy. Another example of strategy is how training data is fed into a network—batch size, full table, or single samples. I imagine, a truly rational agent would strive to dynamically adjust batch size to finish training sooner while maintaining a decent score. This can be a game.

The primary contribution of this paper is introduction of the compositional game theory, a framework for applying a game theory in a composable way, previously mostly contemplated for economic modeling, into the context of neural networks. As we later show, this lens allows us to create a toolkit for improving the performance of machine learning models by making architectural decisions according to strategy modeling. This is not only applicable to neural networks, but also to a wider class of machine learning models.

It will also be demonstrated how one can further expand the game of learning to include its environment and build even more complex games, forming a unyfing framework for a large subset of artificial intelligence studies and practice. We hope that such a unification will offer valuable practical insight into building learning systems of the future.

Connections with Biology and AI Ethics

Human brains are neural networks. We have models of how they work but can't implement them. Most ANNs are simpler structures. Yet, AI uses metaphors of the human mind—attention, memory, ethics, neurons. AI models human experiences to reproduce human-like behavior.

We can express human cognition in terms of games. Emotions, controlled by hormones, influence cognition. We can imagine a function that regulates emotions as a player in a game where the goal is to maximize a fulfilling and virtuous life.

We could introduce an emotional core into AI, regulating "emotional" processes. This core could be modeled in game-theoretic terms, maximizing a fulfilling and virtuous life, used in AI ethics.

Building Neural Games Deep and Wide: Intuition

"Deep learning" refers to how deeply it interacts with data. Well-developed models perform better. Their higher score might indicate deeper understanding. Metrics are arbitrary, guiding our focus on understanding data.

Optimizing neural network performance requires focusing on how the model interacts with data—reading samples, forming attention layers, using windows. These are strategies different models employ in the game of understanding data.

Expressing the overall game of learning as a game controlling subgames relates to optimal control problems. We could model each player individually, giving them autonomy for overall cooperation. Both approaches might be equivalent.

[1]: Definition 1. An $n$-player higher order simultaneous move game is defined by the following data:

  • Sets $X_1, ... , X_n$ of \emph{choices} for each player
  • A set $R$ of \emph{outcomes}
  • An \emph{outcome function} $q$: \prod_{i=1}^{n}{X_i \to R}
  • For each player $1 <= i <= n$, a \emph{multi-valued selection function} $\delta_i: (X_i \to R) \to \mathcal{P}(X_i)$
